STEP 7X — HUMAN AUTHORIZATION MATRIX

GENERAL

Official Step 7X governance mutation requires attributable HUMAN actor.


CAREGIVER

ALLOWED:
- document resident medication refusal as factual event
- document observed administration exception where authorized workflow allows
- document factual possible adverse reaction observation
- request nurse review

DENIED:
- prescribing
- dose decision
- PRN decision
- medication hold decision
- medication resume decision
- independent clinical order review


NURSE

ALLOWED:
- medication reconciliation documentation
- reconciliation review where authorized
- medication order governance review
- medication safety / readiness check
- high-risk first or second check where authorized
- administration exception documentation
- adverse reaction observation
- request escalation

A nurse cannot occupy both sides of the same required independent double-check.


SUPERVISOR / CARE MANAGER

ALLOWED:
- governance oversight
- assign human reviewer
- review unresolved discrepancy workflow
- ensure independent-check accountability


AUTHORIZED MEDICATION REVIEWER

ALLOWED:
- perform assigned medication governance review
- review discrepancy
- review adverse reaction observation
- document human resolution / follow-up

Clinical prescribing authority remains outside this governance domain.


AI / SYSTEM

AI = advisory only.
SYSTEM = infrastructure only.

DENIED:
- medication reconciliation completion
- official order review
- official safety check
- first high-risk checker
- second high-risk checker
- prescribe medication
- select medication
- PRN decision
- dose decision
- route decision
- frequency decision
- medication hold decision
- medication resume decision
- medication discontinuation
- medication administration
- administration confirmation
- adverse reaction diagnosis

HUMAN ACCOUNTABILITY = REQUIRED
INDEPENDENT HUMAN CHECK = REQUIRED WHERE POLICY REQUIRES
