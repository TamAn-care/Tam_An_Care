# Tam An Care V7.4.3 — Step 7W
## Infection Prevention / Infection Surveillance / Communicable Disease Safety

### Purpose

Provide a human-accountable framework for:

- infection-related factual observation
- communicable-disease surveillance
- possible exposure documentation
- human-confirmed infection-control precautions
- monitoring
- safety alerting
- escalation
- resolution
- audit

### Core safety principles

1. Observation is not diagnosis.
2. Exposure history is not confirmation of infection.
3. Symptom cluster is not diagnosis.
4. Temperature or vital-sign change alone does not diagnose infection.
5. AI output is advisory only.
6. Clinical diagnosis remains human responsibility.
7. Precaution decisions require authorized human confirmation.
8. Medication decisions remain in medication workflow.
9. Antibiotic / antiviral selection is outside Step 7W.
10. Emergency or transfer decisions remain human decisions.
11. Official state mutation requires transaction + row lock.
12. Incompatible concurrency requires a single winner.
13. Failed mutation creates zero business mutation and zero audit.
14. Cross-domain clinical mutation is never autonomous.

### Domain flow

Resident
-> Infection Prevention / Control Plan
-> Infection Observation
-> Optional Exposure Event
-> Human Review
-> Optional Human-Confirmed Precaution
-> Monitoring
-> Human-Confirmed Alert
-> Optional Escalation
-> Human Review / Resolution
-> Audit

### Explicitly prohibited autonomous behavior

Step 7W cannot autonomously:

- diagnose infection
- diagnose sepsis
- diagnose COVID-19
- diagnose influenza
- diagnose pneumonia
- diagnose urinary infection
- diagnose wound infection
- prescribe antibiotic
- prescribe antiviral
- modify antimicrobial dose
- administer medication
- order isolation
- order quarantine
- transfer resident
- call emergency service
- create incident
- create care action
- create care task
