# Tam An Care V7.4.3 — Step 7T
## Behavioral / Cognitive / Dementia Safety Management

### Purpose

Provide an auditable, human-accountable domain for documenting
cognitive observations, behavioral episodes, wandering/elopement
events, individualized non-pharmacological support strategies,
human responses, escalation, follow-up and post-event review.

The domain does not diagnose dementia, delirium, psychiatric illness
or other medical conditions.

### Core principles

1. Observation is distinct from diagnosis.
2. Human review is required for official clinical or care decisions.
3. Resident dignity, privacy, autonomy and least-restrictive support
   are mandatory design constraints.
4. A behavioral label must not be used as a substitute for documenting
   observable facts.
5. Potential reversible causes require human clinical review when
   appropriate.
6. AI may detect patterns and raise advisory alerts only.
7. AI cannot create official incidents, prescribe treatment, order
   restraint, sedation, medication, transfer, isolation or emergency
   intervention.
8. All official mutations require an attributable human actor.
9. State-changing operations use transaction + row lock + state
   revalidation.
10. Incompatible concurrent mutations are single-winner.
11. Failed/losing mutations produce zero business mutation and zero
    audit event.
12. Cross-domain mutations are explicit human actions only.

### Domain flow

HUMAN OBSERVATION
-> HUMAN REVIEW
-> OPTIONAL SUPPORT PLAN
-> BEHAVIORAL / WANDERING EVENT
-> HUMAN RESPONSE
-> OPTIONAL ESCALATION
-> HUMAN RESOLUTION
-> POST-EVENT REVIEW
-> FOLLOW-UP
-> AUDIT

### Scope

- cognitive observations
- orientation / memory observations
- observable behavioral changes
- agitation/restlessness observations
- wandering / exit-seeking / elopement events
- known triggers and preferences
- individualized non-pharmacological support strategies
- response documentation
- escalation
- post-event review
- amendment/correction
- audit

### Out of scope

- autonomous diagnosis
- autonomous dementia staging
- autonomous delirium diagnosis
- autonomous psychiatric diagnosis
- autonomous medication change
- autonomous sedation
- autonomous restraint
- autonomous seclusion/isolation
- autonomous transfer
- autonomous emergency-service decision
- autonomous care-task creation
- autonomous incident creation
