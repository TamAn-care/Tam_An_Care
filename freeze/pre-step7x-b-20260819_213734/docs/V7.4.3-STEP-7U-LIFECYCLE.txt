STATE MUTATION CONTRACT

BEGIN TRANSACTION
-> SELECT TARGET FOR UPDATE
-> REVALIDATE STATE
-> VALIDATE HUMAN AUTHORITY
-> VALIDATE OWNER / REVIEWER
-> BUSINESS MUTATION
-> AUDIT
-> COMMIT

Incompatible concurrent transitions are single-winner.

Loser mutation = zero business mutation.
Loser audit = zero audit.

Owner preservation = required.
Reviewer preservation = required.
