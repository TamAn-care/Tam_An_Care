# Tâm An Care V7.3.2 — Health Trend AI

## Purpose
V7.3.2 upgrades Health Trend AI from the V7.3.1 insufficient-data placeholder to a transparent, deterministic longitudinal rules engine.

## Input
POST `/api/ai/engines/health-trend/analyze`

```json
{
  "userId":"demo-care-manager",
  "subjectId":"demo-resident-trend-001",
  "subjectType":"resident",
  "data":{
    "observations":[
      {"date":"2026-07-18","weightKg":63,"foodFluidIntakePercent":72,"sleepHours":7,"spo2":97,"mobility":"ASSISTED"},
      {"date":"2026-07-25","weightKg":62.1,"foodFluidIntakePercent":68,"sleepHours":6.2,"spo2":96,"mobility":"ASSISTED"},
      {"date":"2026-08-01","weightKg":61,"foodFluidIntakePercent":63,"sleepHours":5.2,"spo2":94,"mobility":"ASSISTED"},
      {"date":"2026-08-08","weightKg":60.4,"foodFluidIntakePercent":59,"sleepHours":4.9,"spo2":94,"mobility":"ASSISTED"},
      {"date":"2026-08-15","weightKg":59.8,"foodFluidIntakePercent":55,"sleepHours":4.5,"spo2":93,"mobility":"HIGH_ASSISTANCE"}
    ]
  }
}
```

## Logic
- Minimum 3 valid dated observations.
- Metrics: weight, food/fluid intake, sleep, SpO2 and mobility.
- Detects direction and percentage change between first and latest valid observation.
- Weight <= -5%, intake <= -15%, SpO2 <= -3% contribute high deterioration signals.
- Sleep <= -20% contributes high deterioration.
- Mobility worsening contributes deterioration points.
- Overall trend: DETERIORATING / IMPROVING / STABLE / INSUFFICIENT_DATA.
- Confidence is a rules-engine confidence indicator, not clinical probability.

## Governance
Risk Class B. Human review is required. Autonomous clinical action is prohibited. No production ML model is connected.
