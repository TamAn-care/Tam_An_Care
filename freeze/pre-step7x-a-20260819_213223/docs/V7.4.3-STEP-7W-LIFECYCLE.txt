STATE MUTATION CONTRACT

BEGIN TRANSACTION
-> SELECT target FOR UPDATE
-> reload current state
-> verify human actor
-> verify authority
-> verify owner / reviewer where applicable
-> mutate
-> same-transaction audit
-> COMMIT

Incompatible concurrent mutation = exactly one winner.

Loser business mutation = zero.
Loser audit = zero.

Owner preservation = required.
Reviewer preservation = required.
