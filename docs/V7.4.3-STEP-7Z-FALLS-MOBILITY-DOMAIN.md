# Tam An Care V7.4.3 — Step 7Z
## Falls / Mobility / Transfer Safety Management

### Purpose

Provide human-accountable management of:

- fall-risk assessment
- mobility support planning
- transfer safety
- near-fall documentation
- fall-event documentation
- post-fall factual observations
- fall-prevention actions
- escalation
- audit

### Core principles

1. Fall-risk score is not a diagnosis.
2. AI risk signal is not a clinical finding.
3. Mobility limitation requires attributable human assessment.
4. Transfer assistance level requires human authorization.
5. A fall event does not automatically establish injury.
6. Post-fall factual observation does not diagnose fracture or head injury.
7. Restraint decisions are outside autonomous system authority.
8. Medication changes are outside Step 7Z authority.
9. Emergency transfer decisions require authorized human clinical process.
10. Prevention actions must preserve dignity and mobility rights.
11. Verified records are append-only corrected.
12. Incompatible concurrent state mutations require single-winner semantics.

### Canonical flow

Human Fall-Risk Assessment
-> Verification
-> Mobility Support Plan
-> Human Review
-> Activation
-> Transfer Safety Check
-> Fall / Near-Fall Event
-> Human Assignment / Acknowledgement
-> Post-Fall Observation
-> Prevention Action
-> Optional Escalation
-> Resolution / Closure
-> Audit

### No autonomous clinical decision

AI / SYSTEM cannot:

- diagnose fracture
- diagnose head injury
- diagnose concussion
- diagnose neurological injury
- prescribe imaging
- prescribe medication
- hold medication
- prescribe restraint
- initiate physical restraint
- decide hospital transfer
- decide emergency department transfer
- change mobility restriction
- change assistive-device prescription
- create another clinical-domain action
