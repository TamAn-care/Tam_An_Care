## 2. Quy Chuẩn Trạng Thái Giường & Màu Sắc Nhận Diện
- **`ĐANG SỬ DỤNG`** (`OCCUPIED`): Màu đỏ (`badge-danger` / `#dc2626`) — Có người cao tuổi đang lưu trú.
- **`CÒN TRỐNG`** (`AVAILABLE` / `UNOCCUPIED`): Màu xanh lá (`badge-success` / `#16a34a`) — Sẵn sàng tiếp nhận.
- **`ĐÃ GIỮ CHỖ`** (`RESERVED`): Màu vàng cam (`badge-warning` / `#d97706`) — Hồ sơ đang làm thủ tục nhập viện.
- **`TẠM NGƯNG / BẢO TRÌ`** (`TEMPORARILY_UNAVAILABLE` / `MAINTENANCE`): Màu xám (`badge-neutral` / `#64748b`) — Bảo dưỡng thiết bị, vệ sinh buồng.
