# Tam An Care V7.4.3 — Step 7X
## Medication Safety / Medication Reconciliation / High-Risk Medication Governance

### Architectural position

Step 7X is a governance extension of the existing medication domain.

Existing operational medication objects remain authoritative:

- medication_orders
- medication_schedules
- medication_administrations
- medication_double_checks
- medication_audit

Step 7X MUST NOT duplicate or replace the medication administration engine.

### Purpose

Provide human-accountable governance for:

- medication reconciliation
- reconciliation discrepancy review
- medication order safety review
- readiness / safety check
- policy-defined high-risk medication independent check
- medication administration exception documentation
- adverse reaction observation
- escalation / audit governance

### Fundamental rules

1. Reconciliation does not create or modify a medication order.
2. Medication list discrepancy is not an automatic medication change.
3. Safety signal is not a prescribing decision.
4. Interaction signal is not a clinical diagnosis.
5. High-risk classification comes from approved human/policy configuration.
6. No hardcoded drug-specific treatment rule.
7. Independent double-check requires a distinct accountable human.
8. AI cannot impersonate first checker or second checker.
9. PRN administration requires authorized human decision.
10. No AI dose selection or dose modification.
11. No AI medication discontinuation.
12. No AI administration confirmation.
13. Failed mutation = zero business mutation + zero audit.
14. Incompatible concurrency = single winner.
15. Existing medication order and administration records remain authoritative.

### Governance flow

Human Medication Reconciliation
-> Human Reconciliation Review
-> Reconciliation Discrepancy Documentation
-> Human Medication Order Review
-> Human Safety / Readiness Check
-> If policy-defined high-risk:
   Independent Human Double-Check
-> Existing Medication Administration Workflow
-> Optional Administration Exception
-> Optional Adverse Reaction Observation
-> Human Escalation / Review
-> Audit

### Explicit exclusions

Step 7X cannot autonomously:

- create medication order
- prescribe medication
- prescribe PRN
- choose PRN medication
- change dose
- change route
- change frequency
- discontinue medication
- hold medication clinically
- resume medication clinically
- administer medication
- mark medication administered
- fabricate double-check
- diagnose adverse drug reaction
- create emergency transfer
