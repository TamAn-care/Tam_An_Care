## IMPLEMENTATION PRINCIPLES

1. Validate canonical resident once.
2. Never widen source-domain authorization.
3. Never invoke execute()/mutation methods.
4. Prefer exported domain-owned read services.
5. Do not create integration-layer clinical business logic.
6. Preserve source provenance.
7. Represent domain failure explicitly.
8. Use independent bounded read aggregation.
9. Avoid N+1 resident lookup.
10. Avoid circular NestJS module dependencies.

## PERFORMANCE CONTRACT

Independent reads may execute concurrently.

Preferred aggregation primitive:

Promise.allSettled()

provided that:

- operations are read-only;
- they are independently safe;
- concurrency is bounded;
- one domain failure does not erase successful domains.
