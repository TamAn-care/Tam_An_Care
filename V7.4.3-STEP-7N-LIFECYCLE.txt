STEP 7N LIFECYCLE


CLINICAL OBSERVATION

RECORDED
  -> VERIFIED
  -> AMENDED

RECORDED
  -> VOIDED

VERIFIED
  -> AMENDED

AMENDED represents that one or more amendment
records exist.

Original record remains preserved.


------------------------------------------------

NURSING NOTE

DRAFT
  -> SIGNED

DRAFT
  -> VOIDED

SIGNED
  -> AMENDED

SIGNED is immutable.

Amendment creates a new attributable correction /
superseding record.


------------------------------------------------

ABNORMAL FINDING

OPEN
  -> ACKNOWLEDGED
  -> UNDER_REVIEW

UNDER_REVIEW
  -> ESCALATED

UNDER_REVIEW
  -> CLOSED

ESCALATED
  -> CLOSED


No AI actor may directly perform these transitions.


------------------------------------------------

CLINICAL ESCALATION

OPEN
  -> ASSIGNED
  -> ACCEPTED
  -> RESOLVED

OPEN
  -> CANCELLED

ASSIGNED
  -> CANCELLED

ACCEPTED
  -> RESOLVED


Care Action linkage may occur during human review
or resolution workflow.

Care Action auto-creation = NO.

CONCURRENCY

All competing state transitions use row locking.

Exactly one valid transition wins.

Loser:
HTTP business rejection
ZERO mutation
ZERO audit.
